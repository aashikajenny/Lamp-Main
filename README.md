# OM Night Lamp website

A single-page product site for the OM Night Lamp. A real-time 3D model of the lamp (Three.js) travels, turns and lights up as you scroll. It uses GSAP ScrollTrigger and Lenis smooth scrolling.

## Run

Open `index.html` in a browser, ideally through a local web server. You need an internet connection for the fonts and libraries.

The site opens in a dark room: click the wall switch to light the lamp and enter.

## Before going live

In `script.js`, paste the Amazon, Flipkart and Meesho listing URLs into `CONFIG.stores`. While a link is empty, its button shows a "listing coming soon" note.
